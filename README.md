# panel

# NYX · AETHERCORE EDGE

پنل دوزبانهٔ فارسی/English برای مدیریت کاربران و اشتراک، همراه با یک Worker، آداپتور Pages Functions و برنامهٔ مستقل Gcore FastEdge. این مخزن توسعه‌ای است و **آمادهٔ فروش یا استقرار حساس بدون بررسی امنیتی، حقوقی و آزمون واقعی نیست**.

**هشدار:** هر کلیدی که در چت افشا شده است باید فوراً در ارائه‌دهنده لغو و جایگزین شود؛ کلید جایگزین را در چت، فایل مخزن یا تاریخچهٔ Git قرار ندهید.

## وضعیت واقعی

| بخش | وضعیت و مرز ادعا |
| --- | --- |
| Cloudflare Worker | پنل، D1، VLESS/Trojan روی WebSocket و TCP در محیط محلی Miniflare آزمایش شده‌اند؛ استقرار ابری انجام نشده است. |
| Cloudflare Pages | آداپتور `pages/functions`، D1 و همان تبادل محلی WebSocket آزمایش شده‌اند؛ اتصال ابری Pages تأیید نشده است. |
| Gcore FastEdge | `geo-page` مستقل به Wasm ساخته و در runtime محلی Gcore آزموده شده؛ **پنل یا پروکسی FastEdge نیست** و URL عمومی ندارد. |
| شبکهٔ ایران و DPI | تشخیص و رتبه‌بندی فقط برای URLهای مجاز و از محیط edge انجام می‌شود؛ آزمون از شبکهٔ ایران یا تضمین عبور انجام نشده است. |
| سهمیه و هزینه | شمارندهٔ بایت و سقف تک‌اتصال تقریبی‌اند؛ سهمیهٔ توزیع‌شده و صورتحساب قابل اتکا نیست. هزینهٔ ارائه‌دهنده نامعلوم است. |
| هوش مصنوعی و تلگرام | opt-in و آزمایش با ارائه‌دهندهٔ شبیه‌سازی‌شده؛ اتصال واقعی، مدل‌های قابل دسترس و هزینه تأیید نشده‌اند. |

راهنمای گام‌به‌گام فارسی، از نصب تا پشتیبان‌گیری و استقرار: **[docs/DEPLOYMENT_FA.md](docs/DEPLOYMENT_FA.md)**. نتیجهٔ تست‌ها و محدودیت‌ها: [docs/VERIFICATION.md](docs/VERIFICATION.md) و [docs/SECURITY_AND_LIMITS.md](docs/SECURITY_AND_LIMITS.md).

## اجرای محلی

Node.js 22 و npm لازم است. این دستورها فقط برای محیط توسعه هستند:

```sh
npm ci
cp .dev.vars.example .dev.vars
# در فایل .dev.vars روی دستگاه خود، رمز تصادفی ۱۶ تا ۲۵۶ کاراکتری قرار دهید.
npm run dev
```

سپس `http://localhost:8787/` را باز کنید؛ مدیریت کاربران در `/panel` است. فایل `.dev.vars` و دادهٔ محلی D1 در Git قرار نمی‌گیرند. برای Pages جداگانه، نمونهٔ متغیرها را به `pages/.dev.vars` کپی کنید و `npm run dev:pages` را اجرا کنید. نبود D1 یا رمز اولیه، مسیرهای عملیاتی را به‌صورت بسته متوقف می‌کند.

```sh
npm run check       # typecheck، آزمون‌ها، buildها و اسکن محدود اسرار
npm audit           # بررسی وابستگی‌های شناخته‌شده
npm run sbom        # بازتولید SBOM از lockfile
```

`geo-page/wasm/geo-page.wasm` خروجی ساخته‌شده است و عمداً در Git ذخیره نمی‌شود؛ با `npm run build:geo` ساخته می‌شود.
